# M8a Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Export one note to a self-contained HTML file or an A4 PDF, from the board's card menu or `Ctrl+E`.

**Architecture:** `noite-core` gets `content::exportFileName`, `Store::exportScratch(id, path, ExportFormat)` (new `store_export.cpp`) and `last_export_dir`. `BoardWindow` adds the menu action, a `Ctrl+E` shortcut and two seams (path picker, error reporter).

**Tech Stack:** C++20, Qt 6.10.3 (QtGui: `QTextDocument`, `QPdfWriter`, `QSaveFile`), Qt Test.

**Spec:** `docs/superpowers/specs/2026-10-21-m8a-export-design.md` (X1–X14)

## Global Constraints

- No new Qt module: the single-exe static build is qtbase only.
- Edit sources with the Edit tool, not PowerShell text round-trips.
- Build `tools\build.ps1 -Config Release`; tests `tools\run-tests.ps1 -Config Release` → `TOTAL failures: 0`.
- Only the core writes files (D14).

## Review Focus

1. **Images:** the PDF embeds the original bytes. A scaled-down wide image must not be recompressed at screen size. → Task 2: the width is set on the `QTextImageFormat`; the resource stays the original `QImage`.
2. **`toHtml()` output:** Qt may write the image name with entities or a different quote style. → Task 2: replace by id from `content::attachmentRefs`, test with a real `toHtml()` round-trip.
3. **Partial files:** a failed write must leave nothing. → `QSaveFile` for HTML; a temporary file and rename for PDF; tested with a read-only target.
4. **The overlay's unsaved edits** must be in the export (X14). → Task 3 test.
