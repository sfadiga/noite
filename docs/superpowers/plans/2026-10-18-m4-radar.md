# M4: the Radar (Morning Review) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A once-a-day review that steps through overdue, due-today and stale notes (Done / Snooze / Keep / Trash), opening by itself on the first unlock after the day starts, with noite starting with Windows.

**Architecture:**
- noite-core gains the review queue, `touch`, the last-review day and the `staleDays` setting.
- The app gains three new pieces: `ReviewScheduler` (pure decision logic over an injected clock and lock state), `ReviewWindow` (one note at a time) and an autostart helper behind a registry interface.
- `NativeHost` reports session unlock and resume. `App` wires everything together and adds two tray items.

**Tech Stack:** C++20, Qt 6.10 Widgets/Test, Win32 (WTS session notifications, `WM_POWERBROADCAST`, HKCU Run key via `QSettings`), SQLite.

**Spec:** `docs/superpowers/specs/2026-10-18-m4-radar-design.md` (R1–R6; project spec D16, D31–D34, D4)

## Global Constraints

- Review order (R2): overdue (most overdue first) → due today (oldest first) → stale (longest untouched first). Only these three groups (R3).
- Stale: `status = 'active' AND due_date IS NULL AND modified_at <= now - staleDays·day`; `staleDays` default 7, valid 1–90.
- Keep = `touch` (`modified_at = now`), nothing else changes (R4).
- Snooze quick picks: Tomorrow = today + 1; Next Monday = the next Monday strictly after today (today + 7 when today is Monday); Pick… = calendar.
- The review counts as shown when it opens, or silently when the queue is empty (R6). The tray's "Morning review" never touches `lastReviewDay`.
- Header texts: `OVERDUE · %n day(s)`, `DUE TODAY`, `STALE · %n day(s) untouched`. Summary: `Done %1 · Snoozed %2 · Kept %3 · Trashed %4`.
- Autostart value: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, name `noite`, data `"<exe>"`, plus ` --data "<dir>"` only when the data folder isn't `<exe dir>/data`.
- Tray items: `Morning review`, `Start with Windows` (checkable).
- Test command: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1 -Config Debug -Test` → `TOTAL failures: N`.
- Edit files only with the Edit/Write tools.

## Review Focus

1. Day-start passes while the PC is in use (unlocked, app running) → the review opens at `dayStart` from the timer, once. Test: Task 2 `timerAtDayStartTriggersOnce`.
2. A note edited mid-review elsewhere (e.g. trashed from the board) → that step is skipped with a status line, never a crash. Test: Task 4 `noteGoneElsewhereIsSkipped`.
3. Snooze on a Monday → "Next Monday" is a week later, not today. Test: Task 4 `snoozeDates`.
4. A note captured today at 23:59 isn't stale tomorrow at 06:00 (stale counts whole days since `modified_at`, with N = 7). Test: Task 1 `staleBoundaryIsExactlyNDays`.
5. A data folder path with spaces or non-ASCII characters → the Run command is quoted correctly and round-trips. Test: Task 3 `commandQuotesPathsWithSpaces`.
